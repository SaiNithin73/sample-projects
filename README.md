# 🌟 Interactive Mini-Projects Collection

Welcome to the **Interactive Mini-Projects** repository! This collection features a variety of small, engaging, and highly interactive web applications designed to deliver smooth user experiences and explore different frontend technologies.

## 🚀 Projects Included

Here is a quick overview of the interactive projects currently available in this repository:

### 1. Interactive Blooming Tulips
A visually engaging webpage featuring an animation of blooming tulips. 
* **Features:** Auto-blooming functionality, click-to-bloom interactions, and animated environmental details (like butterflies and curvy stems).
* **Tech Stack:** HTML5 Canvas, JavaScript, CSS.

### 2. Dynamic Digital Clock & Theme Switcher
A highly customizable digital clock that allows users to seamlessly swap between different visual aesthetics.
* **Features:** Real-time clock updates and an interactive theme switcher (featuring Neumorphism, Cyberpunk Neon, etc.).
* **Tech Stack:** React, CSS.

### 3. Student GPA & CGPA Calculator
A practical, interactive tool specifically tailored for students to quickly calculate their academic standing.
* **Features:** College student mode (GPA/CGPA calculations), a dedicated mode for school students, and a built-in dark mode toggle.
* **Tech Stack:** React.

### 4. Interactive Quiz Application
A full-featured quiz platform that tests users' knowledge and tracks their scores.
* **Features:** User authentication, dynamic question loading, and attempt tracking.
* **Tech Stack:** Frontend Framework, SQL Database (Users, Quizzes, Questions, Attempts tables).

---

## 🛠️ Technologies Used

Across these projects, you will find implementations using:
* **Frontend:** React, HTML5 Canvas, Vanilla JavaScript, CSS/Tailwind
* **Backend/Database:** MySQL (for data-driven apps like the Quiz)
* **Design:** Neumorphism, Dark Mode UIs
